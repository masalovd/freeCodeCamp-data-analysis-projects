# freeCodeCamp Data Analysis with Python Projects

This repository contains five projects I completed for the **freeCodeCamp Data Analysis with Python Certification**. Together, they demonstrate practical skills in data cleaning, statistical analysis, data visualization, and trend forecasting using Python.

## What I achieved

- Built reusable data analysis workflows with **Python, NumPy, and pandas**.
- Applied core statistical methods (mean, variance, standard deviation, percentages, and grouped analysis).
- Created clear analytical visualizations with **Matplotlib** and **Seaborn** (line, bar, box, categorical plots, and heatmaps).
- Performed data filtering, transformation, and feature engineering on real-world style datasets.
- Implemented linear regression–based forecasting for sea-level trend prediction.
- Wrote and passed project test modules to validate analysis logic and outputs.

## Completed projects

1. **Mean-Variance-Standard Deviation Calculator**  
   Built a calculator that computes descriptive statistics across rows, columns, and the full matrix.

2. **Demographic Data Analyzer**  
   Analyzed census-style data to produce key demographic insights and summary metrics.

3. **Medical Data Visualizer**  
   Cleaned medical examination data and produced categorical and correlation visualizations to highlight risk factors.

4. **Page View Time Series Visualizer**  
   Explored long-term traffic patterns and seasonality using line, bar, and box plots.

5. **Sea Level Predictor**  
   Modeled historical sea-level data and projected future trends through regression.

This project collection reflects my ability to move from raw data to tested, interpretable analysis outputs suitable for real-world reporting.
